### About this site

In the spirit of dogfooding, this blog is powered by Ghost CMS running on Docker. It is hosted on a Raspberry Pi 4 running Ubuntu 23.10 within my homelab. The server is exposed to the public via a Cloudflare Zero Trust Tunnel. Cloudflare provides speed and reliability via their CDS network, as well as, providing a secure means to expose the website to the internet.
